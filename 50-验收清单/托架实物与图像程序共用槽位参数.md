# 托架实物与图像程序共用槽位参数

状态：待开始。证据预定 `step05-prototype/`。

- [ ] 制造文件、排版预览和打印配置记录相同槽位数据版本；槽号集合与槽数完全一致。
- [ ] 每个槽的坐标、旋转、名义卡尺寸可从数据复算；抽取 CAD 和预览数据比对，差异在明确的数值容差内。
- [ ] 小样与整件都有实际尺寸和装卡照片，记录槽余量、卡面高度、平整度及插拔表现。
- [ ] 导向、识别、滚轮接触和紧固结构完成实物检查；原件测绘值与新件值并列。
- [ ] 卡边承墨方案、编号与插入方向可辨认；图像程序在释放背面作业前等待翻面确认。

通过条件：实物具备后续试印条件，完整制造数据和对应图像程序能够复现。
