# 打印预检与实印反馈定位（print-preflight）

2026-10-06 在 Epson L8058 证卡/A4 拼版链路上付过真纸（一整张镜像废页）换来的教训。

## 铁律

1. **结构检查 ≠ 核验。** 页数、页面尺寸、内嵌图数全对，图片仍可能上下镜像、第 2 页起整体错位——这两个 bug 当天随真打印任务发了出去。PDF 必须**渲染成图并比对**（亲眼或像素差）才算核验过。
2. **每一页都要看。** 多页 bug 常常只在后面的页（画布状态重置类）。至少抽验第 1 页和末页。
3. **结论要倍差。** 候选方向的像素差比较，次小÷最小 ≥ 1.5 才下结论；不足报 inconclusive，换整格区域或换方法重测。小 patch 采样对内容太敏感，不要单独用它定案。

## 定位「打反了 / 打错了」类实印反馈

1. 渲染**当时实际提交的那份 PDF**（作业记录里指到哪份就验哪份），不是重新生成一份。
2. 取出错位置的整格区域，与源图的候选变换（原样／上下镜像／左右镜像／180°）逐一做平均像素差。
3. 倍差 ≥ 1.5 的那个就是真实方向。实例：镜像 11.2 vs 原样 52.4 → 判定上下镜像，随后在代码里找到了缺失的局部翻转。
4. 用户描述的方向词（「反了」）不可直接当旋转指令——先定位真实变换再改代码，避免「翻转+180」叠成新错。

## 渲染工具坑速查

| 工具 | 坑 | 对策 |
|---|---|---|
| macOS sips | 只渲染第 1 页，且**静默不报错** | pypdf 拆成单页 PDF 再逐页渲染 |
| pypdf `page.images` | 提取顺序≠绘制顺序、颜色不可靠 | 不当方向判据，只做内容存在性检查 |
| 视觉模型接口 | 可能限流 | 确定性像素比对做兜底 |
| Read/截图肉眼看 | 依赖工具可用性 | 与像素比对双轨，谁可用用谁 |

## reportlab 画打印件的坑

- 页面级 `translate(0, page_h*PT)` + `scale(PT, -PT)` 翻转后，`drawImage` 还要做**局部 `translate(x, y+h)` + `scale(1, -1)`**，否则图片上下镜像。
- **`showPage()` 会重置画布状态**：坐标变换、白底填充必须放在每页循环里重设，否则第 2 页起全错。
- 已验证写法参考 epson-print-card 的 `make_pdf`（经实印核对）与修复后的 `make_sheet_pdf`。

## 打印队列提交守则

- 显式锁定纸张选项（Epson `EPIJ_Size=1`＝A4），不赌驱动默认值。
- 本地队列出空 ≠ 已打印（epsonremote 等云中继后面还有一段）；物理出纸要人确认后才算交付。
- 队列选项走白名单，禁 copies/sides/缩放类选项，防止驱动改变拼版语义。
- 多台打印机/多条通道时，队列名做一次性选择存档（人打不了长名字）；程序只在白名单队列里解析。

## 需求侧两句

- 一字之差的术语（「证卡」被打成「正卡」）先一句话确认再动手，理解错了赔一整轮交付。
- 领域只有一种规格时，不要把内部配置升格成命令行参数暴露给人。

## 脚本

```bash
python scripts/verify_sheet.py --pdf 拼版.pdf --page 1 --source 源图.png \
  [--cell 46.7x74.3] [--row 0 --col 0] [--page-mm 210x297]
```

渲染指定页、裁出指定格，输出与源图四个候选方向的整格平均像素差与判定（original 才退出码 0，inconclusive 也非 0）。依赖 Pillow/pypdf（pdftoppm 缺失时自动退 sips 拆页路径）。

测试：`~/.cache/epson-print-card/venv/bin/python -m unittest discover -s tests -v`（用 reportlab 分别生成正确与镜像画法的 PDF 断言判定）。
